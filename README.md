A modern, responsive Weather Application built using Flask (Python) with real-time weather data, hourly & daily forecasts, and an adaptive Day/Night UI for an enhanced user experience.
🚀 Features

🔍 Search Weather by City

📍 Use My Location (Geolocation support)

🌞🌙 Automatic Day/Night Theme (based on sunrise & sunset)

☀️ / 🌙 Sun & Moon Indicator

🌌 Animated Night Sky (Stars)

🌧️🌫️ Weather-Specific Night Themes (Rainy, Foggy, etc.)

⏱️ True Hourly Forecast (time + temperature + weather)

📅 Separate Daily Forecast Section

📱 Mobile Swipe Gestures

👉 Swipe Right → Refresh weather

👈 Swipe Left → Focus city search

🎨 Glassmorphism UI with Animations

⚡ Fast & lightweight (no heavy frontend frameworks)
